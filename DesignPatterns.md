# Design Patterns

* **Creational** - Focus on object creation for flexibility and scalability.
* **Structural** - Organize class and objects for better structure.
* **Behavioral** - Enhance object communication for cleaner logic.

### Creational Patterns

* Abstract Factory
* Builder
* Factory Method
* Prototype
* Singleton

### Structural Patterns

* Adapter
* Bridge
* Composite
* Decorator
* Facade
